# Monika Krol — minimalist personal website

A responsive, single-page static website inspired by the simplicity of independent practitioner websites, with original copy and styling.

## Files
- `index.html` — page content and navigation
- `styles.css` — design, responsive layout, colours and typography

## Before publishing
1. Replace `hello@example.com` in `index.html` with your preferred public email address.
2. Review all copy carefully. It intentionally describes you as a psychotherapy trainee and does not claim that you are a qualified psychotherapist or offer psychedelic-assisted therapy.
3. Images and fonts currently load from Unsplash and Google Fonts, so those services need to be reachable. For a fully self-contained site, download properly licensed image files and update the CSS URLs.
4. Check the domain you want is available before purchasing it.

## Publish for free with GitHub Pages
1. Create/sign in to a GitHub account.
2. Create a public repository named `krolmonika-site` (or another name).
3. Upload `index.html`, `styles.css`, and this README.
4. Open the repository's **Settings → Pages**.
5. Under build/deployment, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
6. GitHub will show the published URL after deployment.

## Connect a custom domain
1. Buy your chosen domain from a registrar.
2. In **Settings → Pages → Custom domain**, enter the domain and save.
3. Follow GitHub's current DNS instructions at your registrar. DNS records vary depending on whether you use an apex domain (e.g. `krolmonika.com`) or `www`.
4. Wait for DNS to propagate, then enable **Enforce HTTPS** when available.

Hosting on GitHub Pages is free for eligible public repositories. You still pay the registrar's domain renewal fee. Do not publish private client information or sensitive personal data on this static site.
